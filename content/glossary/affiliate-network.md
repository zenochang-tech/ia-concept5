## What is an affiliate network?

An affiliate network is the platform that connects [advertisers](advertiser) with [publishers](publisher), giving both sides a shared place to run an [affiliate program](affiliate-program). It handles the technical and operational layer that neither side would want to build alone.

## What it provides

- **Tracking** — recording clicks and matching resulting sales or leads back to the correct publisher.
- **Reporting** — dashboards for both advertisers and publishers to review performance.
- **Payments** — collecting funds from advertisers and distributing [commission](commission) to publishers.
- **Discovery** — helping publishers find relevant offers, and helping advertisers find suitable publishers.

## Network vs platform

"Affiliate network" and "[affiliate platform](affiliate-platform)" are often used interchangeably. In practice, network emphasises the marketplace of advertisers and publishers, while platform emphasises the underlying software and tools that run it.
