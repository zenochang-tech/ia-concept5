## What is a webhook?

A webhook is an automated message sent from one system to a specified URL the instant a particular event happens, rather than waiting to be asked for that information. In affiliate marketing, a webhook commonly fires when a new conversion is tracked, a conversion's status changes, or a payout is processed.

## How it's used

- **Real-time updates** — a publisher's own system can be notified the moment a sale is recorded, without polling for changes.
- **Automation** — data from a webhook can trigger other actions, such as updating a spreadsheet or dashboard automatically.
- **Integration** — webhooks let separate platforms (for example, an affiliate platform and a publisher's internal reporting tool) stay in sync.

## Webhook vs postback URL

A webhook and a [postback URL](postback-url) work in a similar way, sending data automatically when an event occurs, but "postback" is the more common term specifically for conversion notifications sent from an advertiser's tracking system to a publisher's platform, while "webhook" is the broader, general term used across many kinds of software, often accessed through an [API](api-application-programming-interface).
