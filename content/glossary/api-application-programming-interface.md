## What is an API?

An API (Application Programming Interface) is a defined way for two systems to exchange data directly, without a person manually logging in and clicking through an interface. On an affiliate platform, it lets a publisher's or advertiser's own systems talk to the platform automatically.

## Common uses on an affiliate platform

- **Pulling reports** — retrieving clicks, conversions, or earnings data straight into a publisher's own tools.
- **Generating links** — creating tracking links or [deeplinks](deeplink) programmatically at scale, instead of one at a time in the dashboard.
- **Syncing offers** — pulling the current list of available offers or a [product catalogue](product-catalog) into an external system.

## API vs webhook

An API is typically used to request data on demand. A [webhook](webhook) works the other way round, pushing data automatically the moment an event happens, such as a new conversion being recorded.
