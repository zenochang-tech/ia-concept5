## What is cost per install (CPI)?

Cost per install (CPI) is a [commission model](commission-model) used for mobile offers, where a [publisher](publisher) earns a fixed fee each time their link drives a genuine new app install, tracked through [app install tracking](app-install-tracking).

## How it's tracked

- **SDK or tracking link** — the advertiser's app includes tracking that confirms the install came from the publisher's link.
- **Device matching** — the install is matched back to the click, often across devices.
- **Fraud checks** — installs are usually validated to filter out fake or duplicate installs before payout.

## Who uses it

CPI is common among [app publishers](app-publisher) promoting mobile apps, and is often paired with [mobile deep linking](mobile-deep-linking) to send new users straight to a specific in-app screen after install.
