## What is app install tracking?

App install tracking is the method used to record when a user installs a mobile app after clicking a [publisher](publisher)'s link. It is the tracking mechanism behind [cost per install (CPI)](cost-per-install-cpi) offers, where the install itself is the qualifying action.

## How it works

- **Click capture** — the user clicks a link and is routed to the app store, with the click recorded first.
- **SDK confirmation** — an [SDK](sdk-software-development-kit) embedded in the advertiser's app confirms the install and matches it back to the original click.
- **Attribution window** — installs are only credited if they happen within the offer's defined [attribution window](attribution-window).

## Who uses it

This is the core tracking method for [app publishers](app-publisher) and any advertiser running CPI campaigns, since a standard [tracking cookie](tracking-cookie) cannot follow a user from a mobile browser into a freshly installed app.
