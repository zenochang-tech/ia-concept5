## What is an order ID?

An order ID is the unique identifier a merchant's system generates for each transaction. It travels through the tracking chain alongside the sale details, letting a platform tie a specific order back to the click that produced it.

## Why it matters

- **Accurate matching** — the order ID is what ties a sale to a [conversion creation](conversion-creation) record, rather than relying on timing alone.
- **Avoiding duplicate payouts** — if the same order is reported more than once, matching on order ID is central to [deduplication](deduplication).
- **Distinguishing order types** — it also helps identify whether an order was a [direct order](direct-order) or an [indirect order](indirect-order) within the same basket.

## On Involve Asia

Order IDs typically appear in conversion reports, giving publishers a concrete reference when querying a specific sale with an advertiser.
