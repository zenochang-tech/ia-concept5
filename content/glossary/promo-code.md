## What is a promo code?

A promo code is a discount code attached to a [publisher](publisher)'s [offer](affiliate-offer), used at checkout instead of, or alongside, a clicked [tracking link](tracking-link). It lets a [commission](commission) be attributed to the publisher even when a shopper types the code directly rather than following a link.

## How it works

- **Issued per publisher or campaign** — so the advertiser and platform can tell which publisher drove the sale.
- **Applied at checkout** — the customer enters the code to receive a discount.
- **Tracked on redemption** — the system matches the code back to the publisher for validation and payout.

## On Involve Asia

Promo codes are especially common for [coupon and deals publishers](coupon-deals-publisher), whose audiences actively search for a code before buying. Advertisers usually list active codes alongside the offer details so publishers can display accurate, up-to-date discounts.
