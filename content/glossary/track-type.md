## What is track type?

Track type defines which platforms and devices an [offer](offer-page) is set up to track conversions on. Each offer can enable or disable tracking across four [device types](device-type): desktop, mobile web, iOS app, and Android app. Only purchases or actions on an enabled device type are captured as conversions.

## Why it matters

- **Cross-device gaps** — a user might click a link on mobile web but complete the purchase inside the advertiser's iOS app; if iOS app isn't enabled in that offer's track type, the conversion won't be attributed.
- **Advertiser-defined** — track type is set by the advertiser based on which platforms their tracking system supports, not by the publisher.
- **Troubleshooting** — checking an offer's track type is a common first step when investigating [missing conversions](missing-conversions).

## On Involve Asia

Each offer page shows its track type using icons for desktop, mobile web, iOS app, and Android app. Publishers whose audience converts mainly through a specific platform, such as a marketplace's mobile app, should confirm that device type is enabled before building a campaign around the offer, since [conversion creation](conversion-creation) only happens on supported platforms.
