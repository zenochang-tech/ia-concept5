## What is track type?

Track type identifies the technical method an [advertiser](advertiser) used to record a given conversion. Common track types include [server-to-server (S2S) tracking](server-to-server-s2s-tracking), [pixel tracking](pixel-tracking), and [postback URLs](postback-url). It is shown as a field on each tracked conversion, alongside details like the order value and status.

## Why it matters

- **Reliability** — server-to-server and postback tracking tend to be more reliable than pixel-based tracking, which can be blocked by browser settings.
- **Troubleshooting** — if conversions look lower than expected, the track type can help identify whether a technical tracking gap, rather than a genuine drop in sales, is the cause.
- **Transparency** — publishers can see exactly how their results are being measured, not just the final numbers.

## On Involve Asia

Each offer specifies which track type the advertiser has integrated, so a publisher promoting multiple offers can understand why tracking behaves differently between them, for example why one offer's [conversion creation](conversion-creation) appears instantly while another takes longer to register.
