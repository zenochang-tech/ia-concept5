## What is an SDK?

An SDK (Software Development Kit) is a package of tools and code that an [advertiser](advertiser) integrates directly into their mobile app. In affiliate marketing, an SDK is what makes reliable [app install tracking](app-install-tracking) possible, since it lets the app itself report installs and in-app events back to the tracking platform.

## What it enables

- **Install tracking** — confirming when a referred user installs the app.
- **In-app event tracking** — recording actions such as sign-ups, purchases, or level completions once the app is installed.
- **[Mobile deep linking](mobile-deep-linking)** — sending a user straight to a specific in-app screen after they install.

## Why it matters

Without an SDK, an advertiser's app has no reliable way to report back what happens after install, which makes it difficult to attribute app-based conversions to the right [publisher](publisher). SDK integration, alongside an [API](api-application-programming-interface) where relevant, is usually a prerequisite for running app-focused affiliate campaigns.
